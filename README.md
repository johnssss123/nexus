# Nexus – Project Management Dashboard

Nexus is a web-based project management application designed to help users manage projects, tasks, employees, and invoices through a simple and organized dashboard.

## Features

- User authentication and protected routes
- Dashboard with project information
- Employee management
- Project management
- Task management
- Invoice management
- Reusable React components

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- JSON Server (for mock API data)

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/johnssss123/nexus.git
```

### 2. Navigate to the project

```bash
cd nexus
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```
